About

Tech news without the theatre.

ByteBrief is a small public reading project. It collects real headlines, real repositories, real conference dates, and real podcast episodes into one calm page — and it shows where every item came from.

What this is

One feed for the parts of tech worth following: AI, programming, hardware, startups, and security. Each story links straight to the publisher. ByteBrief does not rewrite articles, generate summaries, or re-host other people's work.

The interface is a static site: plain HTML, CSS, and ES modules. There is no build step. A scheduled GitHub Action regenerates a single js/data.json file, and the pages render from it.

Where the data comes from

  • Headlines come from 26 publisher RSS or Atom feeds, fetched directly by the refresh job. No feed proxy sits in the middle.
  • Trending repositories come from GitHub's public daily trending page, with cumulative stars and GitHub's own daily gain when it is shown.
  • Podcast episodes come from Apple's public iTunes lookup API, using each show's Apple ID and RSS feed.
  • Events are curated by hand in scripts/events.json. Confirmed dates link to official event pages; anything without an announced exact date is labelled TBA and shows only its month.
  • Sources are listed in full on the Hub, so you can check the input rather than trust the output.

When it refreshes

The GitHub Actions workflow runs every three hours and commits a new data file when the content changes. If one publisher fails, that source is skipped and its previous stories are kept; the other feeds still update. The timestamp at the top of the feed is when the refresh job last ran, not a promise that every publisher answered.

What ByteBrief does not do

  • No invented prices, viewer counts, deal percentages, or "live now" badges.
  • No ads, sponsored placements, tracking pixels, or analytics scripts.
  • No account wall. Reading is public; Google sign-in only exists for saving stories, topics, and your profile.
  • No re-hosting of article text. Descriptions and images belong to the publishers and remain hosted by them.

Known limits

Publisher feeds change without notice. Some images are hotlinked and may fail to load. GitHub's "stars today" is not available on every row, so it is hidden rather than guessed. Podcast hosts are curated, and a show can change hosts at any time. If something is wrong, the fastest fix is an issue on GitHub.

Built with

Static HTML, CSS, and vanilla JavaScript. A Node script handles feed parsing and data generation. Firebase Authentication and Firestore handle optional saving. GitHub Pages hosts the site. The full source is in the ByteBrief repository.

ByteBrief is independent and not affiliated with any of the publications, companies, or events it links to. Headlines and trademarks belong to their owners.
